Software We Support

Field-tested tools we implement, maintain, and support to accelerate secure delivery and reduce operational risk.

DataPower • API Connect

MAST , IBM DataPower Operations Toolkit

MAST provides an automation-first approach to managing IBM DataPower and API Connect environments. It enables policy deployment, configuration promotion, backup/restore, and environment provisioning through standardized, CI-ready workflows. With native Ansible integration and auditing, MAST helps enterprise teams operate large-scale gateway fleets consistently and securely.

Data Workbench

Delve , Data Wrangling & Search

Delve is a data workbench that simplifies event ingestion, exploration, and visualization for engineers and analysts. It provides a pipeline-based query language, dashboards, and an API layer for programmatic access. Delve is ideal for data validation, rapid troubleshooting, and lightweight analytics workflows that complement existing platforms.

Security Analytics

SIEMatic , Events, Dashboards & Alerts

SIEMatic is a forthcoming security analytics and observability platform built on Django and DRF. It features an agent/indexer architecture, an interactive search and dashboard interface, and a modular command pipeline designed for extensibility and clarity. McIndi Solutions is the official provider of commercial SIEMatic licenses and support subscriptions. The product is currently in private alpha, with early-access opportunities for organizations looking to modernize their log ingestion and security visibility stack.

MIT • Client-side

LogSieve , In-Browser Log Exploration

MIT-licensed. LogSieve is a lightweight, client-side web application for exploring and filtering log files. It runs entirely in the browser with no backend or upload required, enabling offline log analysis in secure environments where data must remain on the workstation. Drag and drop a log file to filter, search, and extract fields interactively, ideal for developers and analysts in regulated or air-gapped settings.
