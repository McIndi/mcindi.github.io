      <article class="card">
        <span class="badge">Planning</span>

      </article>
      <article class="card">
        <span class="badge">File Operations</span>
        <h3>Zip Workbench</h3>
        <p>Inspect, edit, and re-download ZIP archives entirely in the browser. Useful for reviewing packages without extracting to disk.</p>
      </article>
      <article class="card">
        <span class="badge">AI Prep</span>
        <h3>Repo2Prompt</h3>
        <p>Download and prepare repository archives for LLM prompt contexts. Package up a codebase for AI analysis without leaving the browser.</p>
      </article>
      <article class="card">
        <span class="badge">Development</span>
        <h3>Regex Workbench</h3>
        <p>Live pattern testing with match highlighting, capture group display, and shareable deep links. Build and validate expressions against real sample data.</p>
      </article>
      <article class="card">
        <span class="badge">Documentation</span>
        <h3>Notes Wiki</h3>
        <p>Markdown-based note-taking with CamelCase linking between entries. A personal wiki that lives in your browser with no sync required.</p>
      </article>
      <article class="card">
        <span class="badge">Publishing</span>
        <h3>Static Page Generator</h3>
        <p>Convert Markdown drafts into standalone HTML pages ready to host anywhere. No build tool or framework required.</p>
      </article>
      <article class="card">
        <span class="badge">Security</span>
        <h3>Secret Share</h3>
        <p>Exchange encrypted, signed secrets with no backend. Uses browser-native crypto and link-based sharing for one-way secret delivery.</p>
      </article>
      <article class="card">
        <span class="badge">Writing</span>
        <h3>Content Studio</h3>
        <p>Plan messaging, draft content, run publishing checklists, and track publication history in a local-first workspace.</p>
      </article>
      <article class="card">
        <span class="badge">Practice</span>
        <h3>TheGym</h3>
        <p>Run structured coding drills with custom exercises, progress tracking, exportable local data, and direct links into practice flows.</p>
